Logistics simulation

Implement method of linear motion along a given network of graph nodes forming a path. Choice of updates is given by

  • evaluation of possible moves (selection if space in front is free)
  • shuffling set of possible moves
  • execution of random sequence of possible moves

  • space is discretized into pots:
    • id
    • local coordinates
    • id of occupying object (0 indicates empty space)
  • objects have their separate structure
    • id
    • field-id of head
discretization into fields and update procedure
